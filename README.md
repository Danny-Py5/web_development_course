# Website Development Course

This repository contains the source code, examples, and practical exercises created while developing a beginner-friendly Website Development Course.

The course is designed to help complete beginners understand how websites are built, starting from the fundamentals of HTML and gradually moving into other core web development technologies.

## 📚 Course Topics

The course covers topics such as:

- HTML fundamentals
- HTML document structure
- Text formatting
- Links and images
- File and folder paths
- Forms
- CSS fundamentals
- JavaScript fundamentals
- Practical website development
- And more

## 🎯 Goal

The goal of this course is to make web development easier to understand by teaching concepts step by step and allowing learners to practice what they learn through real examples.

## 💻 Repository Contents

This repository contains the code written during the course, including:

- Lesson examples
- Practical exercises
- Sample webpages
- Projects
- Practice files

Each section is organized according to the lessons in the course.

## 🛠️ Technologies

The course will primarily use:

- HTML
- CSS
- JavaScript


## 📖 About the Course

This course is being developed as a beginner-friendly learning resource for people who are new to web development.

The focus is not only on writing code, but also on understanding **what the code does, why we use it, and how different parts of a website work together**.
